# 에이푸드 위험성평가 관리 앱

에이푸드(주) 위험성평가, TBM, 개선조치, 순회점검, 설비, MSDS를 엑셀 대신 한곳에서 관리하는 웹앱입니다.
회사 PC 한 대에서 켜 두면 사내 다른 PC와 휴대폰에서도 주소로 접속할 수 있습니다.

## 지금 되는 것 (1단계)

- 기존 정기위험성평가 엑셀 가져오기: 직원명부, 공정목록, 위험성평가, 사진목록, 코드표
- 위험성평가 대장: 부서·공정·점수·공개·작업구분 필터와 검색
- 위험요인 추가·수정: 가능성 × 중대성 자동 계산, 8점 이상 개선대상 표시, 항목ID 자동 부여
- 공개/미공개 전환 (미공개는 위험성평가표 인쇄에서 빠짐), 삭제는 숨김 처리라 복구 가능
- 모든 변경은 이력으로 남음 (누가 무엇을 무엇으로 바꿨는지)
- 위험성평가표 인쇄 (기존 엑셀 모양, A4 가로, PDF 저장 가능)
- 엑셀 내보내기 (기존 "위험성평가_수정추가" 시트와 같은 열 순서)
- 연도 관리: 새 연도를 전년도 복사로 시작, 연도 마감(읽기 전용)

## 2단계: TBM 일지

- 로그인: 이름 + 숫자 PIN. 안전보건담당자(관리자)는 모든 메뉴, 관리감독자는 자기 부서 TBM과 위험요인 추가·수정
- 부서·날짜를 열면 그날 TBM이 자동으로 만들어짐: 부서 공정의 위험요인 4건을 공정별로 돌아가며 배정 (미공개·삭제 항목 제외)
- 위험요인 교체·직접 수정, 팀원 연차·교육 등 선택(출력물 서명칸에 표시), 아차사고·특기사항 입력
- "TBM 완료" 버튼, 완료 후에도 "수정하기"로 다시 열기. 모든 저장은 기록으로 남음
- 출력: 기존 엑셀 "부서(TBM)" 양식, A4 세로. 하루·전체 부서·기간 일괄 출력, 고정 문구는 중국어·베트남어·러시아어·영어 병기 선택
- 재해사례: 공유 시작일부터 7일간 해당 부서 TBM "사고사례 공유" 칸에 자동 포함, 새 사례는 TBM 화면에 알림, 사례마다 플래시카드(화면 넘기기·출력)
- TBM 설정: 부서별 실시 요일, TBM 리더, 팀원과 언어, 안전보건 5계명, 공정 ↔ TBM 부서 연결

## 3단계: 개선조치 · 순회점검 · 근로자 참여

- 개선조치: 위험성 8점 이상 항목과 순회점검 지적사항을 미계획·진행중·지연·완료로 관리. 담당자·예정일·완료일·개선 후 점수 입력, 휴대폰으로 개선 후 사진 바로 찍어 올리기
- 순회점검: 현장 사진 여러 장을 한 번에 올리면 사진마다 기록 칸이 생김. 사진별로 "신규 위험요인으로 등록"(대장에 사진과 함께 추가) 또는 "등록 안 함(조치만 관리)" 선택
- 근로자 참여: 기존 "근로자 위험성평가 참여" 엑셀을 화면에서 올려 근로자·담당 공정·외국어 번역 가져오기. 근로자별 평가지(기존 엑셀 모양, 외국인은 번역) 출력, 근로자가 적은 점수·의견 입력, 평가와 다른 항목은 "반영" 한 번으로 대장 점수 수정 (이력에 남음)
- 메뉴에 "사용자" 탭 추가

## 4단계 (1): 설비 · MSDS · 실시규정

- 설비·안전인증: 기존 "자율안전인증리스트" 엑셀 가져오기, 설비별 점검주기·설치일·담당자, 점검 기록(사진), 다음 점검일 자동 계산, 지연·30일 내 예정·첫 점검 필요 목록, 인증서·신고증명서 PDF 첨부
- MSDS: 물질 목록(구성성분, 사용공정, 월 사용량, 작업환경측정 해당), MSDS Master 엑셀 가져오기, 원본 PDF 첨부, 원본 없음·미게시 확인
- 위험성평가 실시규정: 판별 PDF 보관, 가장 늦은 시행일 판을 현행으로 표시
- 첨부 문서는 `data\files` 폴더에 저장됩니다 (백업 때 `data` 폴더 전체를 복사하세요)

## 4단계 (2): 안전보건 예산 (관리자 전용)

- 편성: 구분별 편성금액·세부내용을 앱에서 입력 (기존 "위험성 평가 예산편성 및 집행" 엑셀의 예산편성 시트도 가져올 수 있음)
- 집행: ERP 계정내역 엑셀을 올리면 전표번호+비고 단위로 비용 줄만 합산하고, 비고 문구(키워드 규칙)로 구분을 자동 분류
  - 지급·대체 전표(미지급금, 보통예금 등)는 세지 않아 이중 집계가 없습니다
  - 수선비처럼 판단이 필요한 건은 "검토"로 남고, 확인/제외를 누르면 다시 가져와도 유지됩니다
  - 키워드 규칙은 화면에서 추가·수정, 부가세 포함 여부 설정 가능
- 집행률, 1인당 집행액(기준 20,000원), 구분별 편성 대비 집행을 한눈에 보고 엑셀로 내보내기

## 4단계 (3): 보건관리 (건강진단 · 작업환경측정 · 보호구)

- 건강진단 (관리자 전용): 기존 "일반/특수/보건증 건강진단 설계" 명단 엑셀 가져오기 (주민번호 뒷자리는 저장하지 않음), 사람마다 일반(1년·사무직 2년)·특수(유해인자별 6/12/24개월)·보건증(1년) 다음 검진일 계산, 지연·30일 내 예정 표시, 판정 C·D·R 사후관리 추적, 기존 모양의 명단 인쇄
- 작업환경측정 (관리자 전용): 상반기·하반기 측정, 유해인자별 측정치·노출기준 (엑셀에서 복사해 붙이기), 기준 초과 표시, 다음 측정일 (6개월, 설정으로 12개월), 결과표 PDF 첨부
- 보호구: 품목(안전인증번호, 교체주기, 최소 재고), 입고·지급·폐기 기록과 재고, 교체 시기가 된 사람 목록. 관리감독자는 지급만 적을 수 있음

다음 단계: 재해사례 자동수집

## 처음 설치 (회사 PC, Windows)

1. **Node.js 설치**: https://nodejs.org 에서 "LTS" 버전(22 이상)을 받아 기본값으로 설치합니다.
2. **Git 설치**: https://git-scm.com 에서 받아 기본값으로 설치합니다.
3. 명령 프롬프트(cmd)를 열고 앱을 둘 폴더로 이동해 내려받습니다.
   ```
   cd D:\AFOOD
   git clone https://github.com/GGoZiZi/afood-safety.git
   cd afood-safety
   npm install
   ```
4. **기존 엑셀 가져오기** (파일 경로는 실제 위치로 바꾸세요)
   ```
   npm run import -- "D:\AFOOD\위험성평가\2026\26년 위험성평가 실시\에이푸드(주) 정기위험성평가_2026.08.10.xlsx" 2026
   ```
   같은 연도를 다시 가져오려면 끝에 `--replace` 를 붙입니다. (그 연도에서 앱으로 고친 내용은 지워집니다)
5. **TBM 회의록 엑셀 가져오기** (부서·리더·팀원·공정 연결·재해사례). 근로자 참여 엑셀은 외국인 팀원 언어 추정용이며 없어도 됩니다.
   ```
   npm run import-tbm -- "D:\AFOOD\위험성평가\2026\TBM 회의록_부서별_2026.01-12.xlsx" 2026 "D:\AFOOD\위험성평가\2026\근로자 위험성평가 참여v1.xlsx"
   ```
   이때 TBM 리더(관리감독자) 계정이 PIN **0000** 으로 만들어집니다. 각자 로그인 후 "사용자" 화면에서 PIN을 바꾸게 하세요.
6. **사진 넣기**: `26년 위험성평가 실시\photos` 폴더의 사진을 `afood-safety\data\photos` 폴더에 복사합니다.
7. `시작.bat` 을 더블클릭합니다. 처음에는 준비하느라 몇 분 걸립니다.
8. 브라우저에서 http://localhost:3000 으로 접속합니다. 처음 한 번은 관리자(안전보건담당자) 이름과 PIN을 정하는 화면이 나옵니다.

## 매일 쓰기

- 켜기: `시작.bat` 더블클릭 (검은 창을 닫으면 꺼집니다)
- 다른 PC·휴대폰에서 접속: 같은 사내망에서 `http://(앱 PC의 IP주소):3000`
  - IP주소는 앱 PC의 cmd에서 `ipconfig` 를 치면 "IPv4 주소"에 나옵니다.
  - 처음 접속 시 Windows 방화벽 창이 뜨면 "개인 네트워크 허용"을 누르세요.
- 백업: `백업.bat` 더블클릭 → `backup` 폴더에 날짜별 DB 파일이 생기고, 사진(`backup\photos`)과 첨부 문서(`backup\files`)도 함께 복사됩니다. 주 1회 이상, `backup` 폴더를 USB나 공유폴더에도 복사해 두세요.
- 업데이트: 새 기능이 올라오면 `업데이트.bat` 더블클릭 후 `시작.bat`

## 데이터 위치

| 무엇 | 위치 |
| --- | --- |
| 모든 기록 (DB) | `data\afood.db` 파일 하나 |
| 사진 | `data\photos` 폴더 |
| 첨부 문서 (PDF 등) | `data\files` 폴더 |

`data` 폴더는 GitHub에 올라가지 않습니다 (직원 연락처 등 개인정보 보호).
나중에 인터넷 서버로 옮길 때도 이 폴더만 옮기면 됩니다.

## 개발자용

- Next.js 15 (App Router) + SQLite(better-sqlite3), 자바스크립트
- `npm run dev` 개발 서버, `npm run build && npm run start` 운영
- DB 스키마: `src/lib/schema.sql` (앱이 켜질 때 자동 적용)
- 환경변수: `AFOOD_DATA_DIR` (DB 폴더), `AFOOD_PHOTO_DIR` (사진 폴더)
